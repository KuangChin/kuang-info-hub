# Kuang Info Hub

個人化情報儀表板，整合台股、財經、世界新聞、NBA、MMORPG 與社群熱門內容。

## 目前功能

- 六大情報分類與即時 RSS 聚合
- AI 技術來源：Anthropic（Google 新聞搜尋）、Hugging Face、Google DeepMind、OpenAI 與 arXiv AI／機器學習
- 關鍵字搜尋與分類篩選
- 自選市場快照（台股取自 TWSE、美股取自 NASDAQ，顯示來源與更新時間）
- 新聞收藏（瀏覽器 localStorage）
- 「推薦／最新」切換：推薦模式由 Claude 依你的讚／倒讚為新聞評分並寫出推薦原因（未設定金鑰時改用規則排序）
- 新聞時間以伺服器更新時間計算，超過一天會同時顯示實際月日
- 相關度與推薦原因
- 響應式深色介面
- RSS 無法連線時自動切換展示資料
- 英文 AI 新聞自動產生繁中標題與摘要（Claude，需設定 `ANTHROPIC_API_KEY`）
- 手機版：可加入主畫面（PWA）、底部導覽列、下拉重新整理、離線顯示上次的新聞

## 本機執行

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`。

## AI 英文新聞摘要

在 Vercel 專案的 Settings → Environment Variables 加入 `ANTHROPIC_API_KEY`（本機放在 `.env.local`），重新部署後即生效。

- 只處理「AI 世界新聞」分類中以英文為主的文章，中文新聞不會送出
- RSS 內容太短時（如 Google 新聞只有標題），會先解出原始網址、抓取原文正文再摘要；被網站阻擋時改依標題整理，卡片標示「僅依標題」
- 預設模型 `claude-haiku-5-5`，可用 `ANTHROPIC_MODEL` 更換
- 每篇依網址、標題與內文快取，同一篇只摘要一次；載入時最多等 3.5 秒，未完成的會在背景完成，下次開啟即可看到
- 若狀態視窗顯示金鑰未綁定工作區（workspace），請改用在工作區內建立的金鑰，或另外設定 `ANTHROPIC_WORKSPACE_ID`
- 未設定金鑰時功能自動關閉，其他功能不受影響

## 重複與類似新聞

- 同一網址的文章只保留一筆
- 報導同一事件的新聞（不同媒體、不同語言、標題寫法不同）由 Claude 判斷歸為一組，再加上標題幾乎相同的規則比對
- 每組只顯示分數最高的一則（AI 喜好分數，沒有時用規則分數），卡片標示「＋N 則類似」
- 只合併同一個具體事件；同公司或同主題但不同事件不會合併
- 收藏頁不合併；未設定金鑰時只用標題比對

## AI 喜好排序

- 讚／倒讚後約 1 秒，網站把最近 30 則回饋的標題與候選新聞送到 `/api/rank`，由 Claude 打 0–100 分並寫原因
- 只接受本站 API 簽章過的新聞，無法塞入任意文字消耗額度；每次最多 120 篇、每個伺服器實例每 10 分鐘最多 40 次請求
- 相同喜好與新聞的結果會快取，喜好不變時只有新出現的新聞需要評分
- 可選 `FEED_SIGNING_SECRET` 指定簽章金鑰（預設由 API 金鑰衍生）

## API

- `GET /api/feed`：聚合新聞情報
- `GET /api/feed?category=nba`：取得指定分類
- `GET /api/market`：市場快照
- `POST /api/rank`：AI 喜好評分
